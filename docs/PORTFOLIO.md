# Antes de enseñarlo como portfolio

1. Ejecuta las comprobaciones pendientes y corrige lo que aparezca en tu entorno.
2. Conecta un Firebase de desarrollo y prueba dos usuarios reales.
3. Añade capturas reales y una grabación breve: crear rutina → completar sesión → consultar historial/gráfico.
4. Conserva la autoría original y describe tu aportación posterior con precisión.
5. No subas `private-config/`, `google-services.json`, claves, certificados ni carpetas build.
6. Genera y confirma el lockfile Node tras instalar las dependencias; revisa CI en tu repositorio.
7. Acuerda una licencia con los autores si queréis permitir reutilización.

Para una publicación pública de producción faltan políticas de privacidad/retención, eliminación/exportación de cuenta, App Check, revisión de seguridad conectada, paginación según el volumen de datos, firma release y distribución. Este código no pretende dar por completadas esas tareas.
